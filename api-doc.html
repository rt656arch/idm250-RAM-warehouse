SKUs

POST /api/v1/skus.php

Creates a new SKU or updates an existing one if the SKU code already exists (upsert behavior).

Required Body Parameters

Field Type Description
sku string Unique SKU code
description string Product description

Optional Body Parameters

Field Type Default Description
ficha integer 0 Internal ficha / reference number
uom_primary string BUNDLE Primary unit of measure (BUNDLE or PALLET)
piece_count integer 0 Pieces per unit
length_inches decimal 0 Length in inches
width_inches decimal 0 Width in inches
height_inches decimal 0 Height in inches
weight_lbs decimal 0 Weight in pounds
assembly string false Requires assembly (true / false)
rate decimal 0 Handling rate

Example Call (PHP)

$api_url = 'https://digmstudents.westphal.drexel.edu/~rt656/ram/api/v1/skus.php';
$api_key = 'ram-key-2026';

$sku_data = [
    'sku'            => '1720813-0132',
    'description'    => 'MDF ST LX C2-- 2465X1245X05.7MM P/EF/132',
    'ficha'          => 724,
    'uom_primary'    => 'BUNDLE',
    'piece_count'    => 250,
    'length_inches'  => 96.00,
    'width_inches'   => 39.00,
    'height_inches'  => 29.65,
    'weight_lbs'     => 3945.22,
    'assembly'       => 'false',
    'rate'           => 15.16
];

$options = [
    'http' => [
        'method'  => 'POST',
        'header'  => "x-api-key: $api_key\r\n" .
                     "Content-Type: application/json\r\n",
        'content' => json_encode($sku_data)
    ]
];

$context  = stream_context_create($options);
$response = file_get_contents($api_url, false, $context);
$result   = json_decode($response, true);

Response (201 — Created)

{
    "success": true,
    "id": 31
}

Response (200 — Updated)

{
    "success": true,
    "message": "SKU updated"
}

Error Response (400)

{
    "error": "Bad Request",
    "details": "Missing required fields: sku, description"
}

Error Response (405)

{
    "error": "Method Not Allowed"
}

MPLs (Master Packing Lists)

POST /api/v1/mpls.php

Creates a new MPL (Master Packing List) in the WMS. Each MPL represents an inbound shipment with one or more inventory units. If a SKU code on an item does not exist in the WMS, it can be auto-created by supplying sku_details.

Required Body Parameters

Field Type Description
reference_number string Unique MPL reference number
items array Array of item objects (see below)

Optional Body Parameters

Field Type Description
trailer_number string Trailer / container number
expected_arrival string Expected arrival date (YYYY-MM-DD)

Item Object Fields

Field Type Required Description
unit_id string Yes Unique unit identifier (barcode / label)
sku string Yes SKU code for this unit
sku_details object No Full SKU data object — required only if the SKU does not already exist in the WMS (auto-creates the SKU)
Auto-create behavior: If a SKU code is not found in the WMS and sku_details is provided, the SKU is automatically created before the MPL is saved. If the SKU is missing and no sku_details are given, the request is rejected with a 400 error listing the missing SKU codes.

Example Call (PHP)

$api_url = 'https://digmstudents.westphal.drexel.edu/~rt656/ram/api/v1/mpls.php';
$api_key = 'ram-key-2026';

$mpl_data = [
    'reference_number' => 'MPL-2024-00123',
    'trailer_number'   => 'TRL-9988',
    'expected_arrival' => '2024-08-15',
    'items'            => [
        [
            'unit_id' => 'UNIT-001-A',
            'sku'     => '1720813-0132'
        ],
        [
            'unit_id'     => 'UNIT-002-B',
            'sku'         => '1720899-0001',   // new SKU — provide details
            'sku_details' => [
                'description'   => 'NEW SPECIES 2X4X8FT KD',
                'ficha'         => 999,
                'uom_primary'   => 'BUNDLE',
                'piece_count'   => 200,
                'length_inches' => 96.00,
                'width_inches'  => 42.00,
                'height_inches' => 36.00,
                'weight_lbs'    => 2900.00,
                'assembly'      => 'false',
                'rate'          => 15.00
            ]
        ]
    ]
];

$options = [
    'http' => [
        'method'  => 'POST',
        'header'  => "x-api-key: $api_key\r\n" .
                     "Content-Type: application/json\r\n",
        'content' => json_encode($mpl_data)
    ]
];

$context  = stream_context_create($options);
$response = file_get_contents($api_url, false, $context);
$result   = json_decode($response, true);

Response (200)

{
    "success": true,
    "message": "MPL received",
    "mpl_id": 42
}

Error Response (400 — Missing reference or items) 

{
    "error": "Bad Request",
    "details": "Missing reference_number or items"
}

Error Response (400 — Unknown SKUs)

{
    "error": "Bad Request",
    "details": "Missing SKUs in WMS: 1720899-0001. Provide full SKU details to auto-create."
}

Error Response (409 — Duplicate MPL)

{
    "error": "Conflict",
    "details": "MPL already exists"
}

Error Response (405)

{
    "error": "Method Not Allowed"
}

Orders

POST /api/v1/orders.php

Creates a new outbound order in the WMS. Every unit listed in items must already exist in the WMS inventory; orders for units not in stock are rejected.

Required Body Parameters

Field Type Description
order_number string Unique order / reference number
items array Array of item objects (see below)

Optional Body Parameters

Field Type Description
ship_to_company string Recipient company name
ship_to_street string Street address
ship_to_city string City
ship_to_state string 2-letter state abbreviation
ship_to_zip string ZIP code

Item Object Fields

Field Type Required Description
unit_id string Yes Unique unit identifier — must exist in WMS inventory
sku string No SKU code (looked up automatically from inventory if omitted)
Inventory check: All unit_id values are validated against current WMS inventory before the order is saved. If any unit is not in stock, the entire request is rejected and no order is created.

Example Call (PHP)

$api_url = 'https://digmstudents.westphal.drexel.edu/~rt656/ram/api/v1/orders.php';
$api_key = 'ram-key-2026';

$order_data = [
    'order_number'    => 'ORD-2024-00789',
    'ship_to_company' => 'Acme Lumber Co.',
    'ship_to_street'  => '123 Main St',
    'ship_to_city'    => 'Philadelphia',
    'ship_to_state'   => 'PA',
    'ship_to_zip'     => '19103',
    'items'           => [
        ['unit_id' => 'UNIT-001-A', 'sku' => '1720813-0132'],
        ['unit_id' => 'UNIT-003-C']    // sku looked up from inventory
    ]
];

$options = [
    'http' => [
        'method'  => 'POST',
        'header'  => "x-api-key: $api_key\r\n" .
                     "Content-Type: application/json\r\n",
        'content' => json_encode($order_data)
    ]
];

$context  = stream_context_create($options);
$response = file_get_contents($api_url, false, $context);
$result   = json_decode($response, true);

Response (200)

{
    "success": true,
    "message": "Order received",
    "order_id": 17
}

Error Response (400 — Missing fields)

{
    "error": "Bad Request",
    "details": "Missing order_number or items"
}

Error Response (400 — Units not in stock) 

{
    "error": "Bad Request",
    "details": "Units not in WMS inventory: UNIT-001-A, UNIT-003-C"
}

Error Response (409 — Duplicate order)

{
    "error": "Conflict",
    "details": "Order already exists"
}

Error Response (405)

{
    "error": "Method Not Allowed"
}
